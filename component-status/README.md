# Component Status Service

## Overview

Lightweight HTTP service that provides information about installed components and features in an Edge Orchestrator deployment. Implements [Proposal 1](https://github.com/open-edge-platform/edge-manageability-framework/blob/main/design-proposals/platform-component-status-service.md) from the Component Status Service Design Proposal.

## API Endpoints

### GET /v1/orchestrator

Returns orchestrator component status as JSON.

**Response Example:**
```json
{
  "schema-version": "1.0",
  "orchestrator": {
    "version": "2026.0",
    "features": {
      "application-orchestration": {"installed": true},
      "cluster-orchestration": {"installed": true},
      "edge-infrastructure-manager": {
        "installed": true,
        "inventory": {"installed": true},
        "out-of-band-management": {"installed": true},
        "device-onboarding": {"installed": false}
      },
      "observability": {"installed": true},
      "multitenancy": {"installed": true}
    }
  }
}
```

### GET /healthz, /readyz

Health check endpoints for Kubernetes probes.

## Configuration

Service uses YAML configuration generated by installer:

```yaml
schema-version: "1.0"
orchestrator:
  version: "2026.0"
  features:
    application-orchestration:
      installed: true
    edge-infrastructure-manager:
      installed: true
      device-onboarding:
        installed: false
```

## Building

```bash
# Local build
cd component-status
make build

# Docker build
make docker-build
```

## Running Locally

```bash
# Create config file
cat > config.yaml <<EOF
schema-version: "1.0"
orchestrator:
  version: "2026.0"
  features:
    application-orchestration:
      installed: true
EOF

# Run service
CONFIG_PATH=./config.yaml PORT=8080 go run ./cmd/component-status

# Test
curl http://localhost:8080/v1/orchestrator
```

## Deployment

### Helm Installation

```bash
helm install component-status ./charts/component-status \
  -n orch-platform --create-namespace \
  --set componentStatus.orchestrator.version="2026.0"
```
